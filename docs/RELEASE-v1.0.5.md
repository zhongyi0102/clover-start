# 归位 v1.0.5 — 当前规则、交互与文件显示更新

本版包含原“四叶草”到“归位”的显示品牌更新，以及应用角色、常用排序、桌面收纳、文件库、壁纸适配和设置交互的累计改进。内部 `CloverStart.exe`、配置和旧开机自启身份保持兼容。

## 本版变化

- 应用统一为用户用的、低价值、电脑用的：电脑入口不平铺但搜索置后，新应用默认用户类，手动分类与隐藏优先。
- 常用移除固定功能，按最近 72 小时面板启动记录统计；明确自动／手动排序并可恢复自动排序。
- 应用、文件与桌面收纳更新尽量复用原控件，保留仍有效的选择、搜索、滚动和阅读位置。内容空白点击取消选择，取消后不误开首项。
- 改善窄窗口与窗口缩放时的网格、标题、筛选栏和底部操作布局，补齐键盘菜单、焦点与多选交互。
- 文件库显示 Windows 文件关联图标和文件夹图标，24px 固定图标槽，文档按扩展名异步缓存；补图标不读取文档内容或重建列表。
- 桌面收纳只承接非应用内容，自由摆放；已确认的应用快捷方式进入回收站，未知入口留原处，同名不覆盖，放回和失败处理保留例外。
- 图片与独立视频自动适配背景，优先保留原色、局部保护文字；动态明暗保持稳定，播放失败回退静态或纯色，不要求运行完整 WE 场景。
- 设置页改为单列整行开关，目录操作集中，技术诊断默认折叠，修改即时生效。
- 安全更新脚本只替换校验后的程序／资源，保留用户数据和旧程序备份。README 已按当前版本重写，不再展示旧版截图。

## 下载选择

- **CloverStart-v1.0.5.zip（推荐）**：便携完整包，包含程序、资源、README、更新脚本、许可证、更新清单及测试证据。
- **CloverStart.exe**：嵌入图标的单文件程序，可独立启动；已有安装推荐使用完整包的更新流程。
- 对应的 **.sha256**：用于核对下载完整性，不等于发布者数字签名。

需要 Windows 10 / 11 和 .NET Framework 4.8。解压后运行 `Launch.bat` 或 `app\CloverStart.exe`；开机自启由用户主动开启。

## 从旧版更新

1. 从右键菜单退出旧程序，不只是收起面板。
2. 解压新 ZIP，保留旧目录，不直接覆盖旧安装。
3. 用 Windows PowerShell 5.1 运行新包的 `tools\update.ps1`，指定新包和旧安装目录，先加 `-DryRun` 检查，再执行更新。

完整命令及程序回退说明见 [安全更新与退出使用](https://github.com/zhongyi0102/clover-start/blob/v1.0.5/docs/UPGRADE.md)。更新不覆盖配置、分类、排序、收纳文件和自定义背景；普通更新失败会尝试恢复旧程序，停电或磁盘故障不保证自动回退。程序回退不等于收纳文件撤销。

**桌面收纳存放的是真实用户文件。不要删除整个安装目录来更新或卸载。**

## 验证与已知限制

本版已通过 Windows PowerShell 5.1 分层校验和编译；2026-11-15 完整测试共 75 个套件、4248 项断言，失败 0。详细执行时间与各套件结果见本包的 `test-summary.json`。测试使用临时目录，不对用户真实桌面执行搬移或修改自启。

以下人工项尚未完成，自动测试不能视作已通过这些场景：真实多显示器及 100%／125%／150%／200% 混合 DPI、不同显卡与动态视频、Office 占用与公共桌面、新包在其他电脑的冷启动和旧安装完整更新流程。建议更新前备份，在自己的环境中确认。

文件库只扫描来源第一层，合计最多枚举 5000 个原始项，不是全盘搜索或同步工具。WE scene 仅使用可用的静态预览，web／application 壁纸不支持；视频独立静音播放，不保证与桌面同步。应用常用只统计从面板启动的记录。
