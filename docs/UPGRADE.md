# 安全更新与退出使用

## 更新

先解压正式发布包，保留旧安装目录，不把新包直接覆盖到旧目录。

在 Windows PowerShell 5.1 中执行新包内的脚本，先检查计划：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "新包\tools\update.ps1" -SourcePackage "新包" -TargetDirectory "旧安装目录" -DryRun
```

确认路径后去掉 `-DryRun` 执行。脚本校验发布清单、每个程序文件 SHA256、程序版本及路径边界；不能读取或修改配置和收纳内容。SHA256 用于发现损坏，不等于发布者签名；只使用你信任的发布来源。

更新前从右键菜单选择“退出”。脚本只尝试正常关闭指定安装目录的进程；只收起面板而没有退出时会停止更新，不强杀其他安装实例、不修改开机自启。

旧程序与旧资源保存于目标目录 `update-backups\时间-唯一编号\`；覆盖中发生普通错误会自动恢复已经替换的文件。停电、磁盘损坏、脚本被强杀不保证自动回退，备份目录仍保留用于手动恢复。

## 程序回退

退出程序，按照备份中的 `journal.json` 把原来存在的程序／资源复制回原相对路径；本次新增的资源可按清单单独移走。不要把整个备份目录覆盖到配置或桌面收纳，不要删除整个安装目录。

程序回退不自动迁移或撤销用户文件；桌面收纳的文件移动应使用面板的撤销／放回流程。

## 退出使用／卸载

1. 从桌面收纳放回需要的内容，或把收纳目录迁到你自己选定的位置。检查自定义收纳路径以及旧 `desktop-backup` 目录。
2. 保留需要的 `config`、自定义背景、使用记录与程序备份。
3. 运行 `app\CloverStart.exe --disable-autostart`，再运行 `app\CloverStart.exe --reset-all --keep-config` 撤销程序对系统的影响。
4. 确认文件已转移且备份可读后，只删除不再需要的程序文件。不要把“删除整个安装文件夹”当作默认卸载步骤。

`--reset-all` 不删除设置、分类、排序与收纳文件，默认只额外清理图标缓存；`--keep-config` 连图标缓存也保留。它不是删除用户数据的命令。
