# Product purpose

四叶草是在 Windows 桌面上快速启动应用、聚合常用文件夹，并把桌面文件收纳进真实目录的常驻效率工具。

# Primary user

每天高频使用 Windows、希望用键盘和鼠标快速找到应用与文件，并在 13–27 英寸桌面屏幕上进行短时操作的个人用户。

# Principles

1. **用户文件安全高于操作速度。** 所有持久化与文件移动都必须可诊断、可恢复，破坏性操作必须明确确认或提供撤销。
2. **高频路径必须近乎瞬时。** 搜索、切页、启动应用不增加装饰性等待；动画只解释状态和空间关系。
3. **不同风险使用不同语言。** 浏览来源叫“文件库”，实际搬运桌面文件叫“桌面收纳”，界面不能让两者看起来等价。
4. **内容优先于玻璃效果。** 以中性色承载信息，只在选中、焦点和关键状态使用单一强调色。
5. **鼠标不是唯一入口。** 主要操作必须具备键盘焦点、可见焦点和可访问名称。

# Success metric for the surface

用户打开面板后能在几秒内找到并启动应用，或进入正确的文件页面；在执行移动、删除和保存时能清楚知道动作结果，失败时获得可恢复的反馈。

# Out of scope

- 不把主面板改造成完整资源管理器。
- 不在本轮进行一次性 MVVM 或 XAML 重写。
- 不引入第三方 UI、动画或图标框架。
- 不改变现有配置文件名、内部分类键和桌面目录名。
- 不用装饰性渐变、霓虹或全控件玻璃化覆盖现有品牌语言。
